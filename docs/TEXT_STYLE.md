# Text Style and Naming

- Product/repository: **ModernQGIS**; platform: **QGIS**; UI term: **Modern Shell**.
- Never describe preview builds as an official QGIS edition.
- Prefer concise action labels and complete error sentences with a useful next action.
- Stable command IDs are lowercase dotted contracts such as `project.open`, `map.full-extent`, `layer.add-vector`.
- IDs never contain translated text.
- English uses sentence case; Japanese uses natural software terminology; Chinese uses concise established GIS terminology where possible.

Release vocabulary is precise: a **build** creates output; an **artifact** is CI output; a **tag** is a source reference; a **GitHub Release** is a published release record. A successful build is not a published release.
