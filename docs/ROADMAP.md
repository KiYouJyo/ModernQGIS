# Roadmap

This document defines intended scope, not promised dates.

## v0.1 — Architecture PoC

Prove ModernQGIS can remain external to the QGIS source tree: Qt/CMake foundation, optional QGIS integration, public action bridge, null bridge, repository/localization/release contracts.

## v0.2 — UI Abstraction Foundation

Add tested Command/Pane/Context registries, isolated native command bindings, diagnostic QAction/QDockWidget discovery, three-language parity checks, and a standalone Foundation Sandbox.

## v0.3 — Modern Shell Alpha

Modern title/navigation layer, Ribbon information architecture, command search, theme foundation, Contents/Properties shell, controlled Classic fallback.

## v0.4–v0.5

Pane lifecycle/plugin adaptation, then Map/Layout/Table/Model/3D-style document workspace.

## v0.6–v0.8

Layer/properties/symbology/labels, editing, analysis/Processing, and plugin/power-user compatibility.

## v0.9

Cross-platform, accessibility, HiDPI, performance, recovery, and QGIS stable/development compatibility matrix.

## v1.0

Primary QGIS workflows can remain in Modern Shell, while advanced legacy dialogs may still be reachable.

A parallel upstream track evaluates generic command/pane/workspace/plugin-UI infrastructure early rather than waiting for v1.0.
