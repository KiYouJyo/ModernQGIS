# ModernQGIS v0.3.0 — Shell Preview

> Development preview. No GitHub Release is published at this stage.

- First reusable Modern Shell implemented directly from the `QGIS Modern` Figma reference.
- Added a 40 px custom title bar, Ctrl+K global search, Ribbon Tabs, and a collapsible Ribbon Workspace.
- Added Contents, document-tab workspace, map-canvas preview, Layer Properties, and a 28 px GIS status bar.
- Promoted Figma colors, spacing, radii, and key geometry to code-level design tokens.
- Added Pane/Ribbon state persistence plus baseline accessible names and tooltips.
- QGIS plugin entry now opens the Modern Shell and binds existing GIS commands through public `QgisInterface` QAction APIs.
- Added a QGIS 4.2 public-API integration build and an offscreen GUI smoke test.
- QGIS itself remains excluded from the ShellPreview package.
