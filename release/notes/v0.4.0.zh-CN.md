# ModernQGIS v0.4.0 — 功能预览

> 首个具备真实 QGIS 工作区与签名 Windows 安装包的功能预览版本；QGIS 本体不随包分发。

- 将中央占位地图替换为真实 `QgsMapCanvas`，并由当前 `QgsProject` 驱动渲染。
- 将 Contents 假图层替换为真实 `QgsLayerTreeView`，支持图层显隐、顺序调整、重命名与活动图层同步。
- 接入平移、放大、缩小、全图显示、单要素选择、缩放至选择与清除选择。
- 接入 Add Data、图层属性、属性表、编辑切换以及项目 New/Open/Save 的 QGIS 公共接口边界。
- 新增 ModernQGIS 自有测距/测面积 MapTool，使用 QGIS 项目 CRS、椭球与 `QgsDistanceArea` 计算。
- 图层属性摘要改为真实图层名称、几何类型/要素数或栅格波段数。
- 状态栏实时显示地图坐标、比例尺、旋转、目标 CRS 与渲染状态。
- 新增 ModernQGIS Launcher：定位本机 QGIS 4.x，并通过 `QGIS_PLUGINPATH` 注入 ModernQGIS 插件目录。
- Windows x64 包含启动器与 QGIS 插件 DLL；二进制与安装器均执行 Authenticode 签名及 SHA-256 校验。
- 保持 `qgisBundled=false`：不复制或分叉 QGIS 本体，QGIS API 变化继续集中在 Bridge 层适配。
