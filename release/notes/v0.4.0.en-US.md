# ModernQGIS v0.4.0 — Functional Preview

> The first functional preview with a real QGIS-backed workspace and a signed Windows installer. QGIS itself is not bundled.

- Replaces the central painted placeholder with a real `QgsMapCanvas` driven by the active `QgsProject`.
- Replaces fake Contents layers with a real `QgsLayerTreeView`, including visibility, ordering, renaming and active-layer synchronization.
- Connects pan, zoom in/out, full extent, single-feature selection, zoom to selection and clear selection.
- Connects Add Data, layer properties, attribute table, editing toggle and Project New/Open/Save through QGIS public API boundaries.
- Adds ModernQGIS-owned distance and area MapTools using the project CRS, ellipsoid and `QgsDistanceArea`.
- Shows live layer names, vector geometry/feature counts or raster band counts in the layer summary.
- Shows live cursor coordinates, scale, rotation, destination CRS and rendering state in the status bar.
- Adds the ModernQGIS Launcher, which locates a local QGIS 4.x installation and injects the installed plugin path through `QGIS_PLUGINPATH`.
- The Windows x64 package contains the launcher and QGIS plugin DLL; binaries and installer are Authenticode-signed and SHA-256 verified.
- Keeps `qgisBundled=false`: ModernQGIS does not copy or long-term fork QGIS, and QGIS API compatibility stays isolated in the Bridge layer.
