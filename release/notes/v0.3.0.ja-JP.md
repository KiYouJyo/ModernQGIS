# ModernQGIS v0.3.0 — Shell Preview

> 開発プレビューです。現時点では GitHub Release を公開しません。

- Figma の `QGIS Modern` デザインを基準に、再利用可能な Modern Shell を初めて実装。
- 40 px カスタムタイトルバー、Ctrl+K グローバル検索、Ribbon Tabs、折りたたみ可能な Ribbon Workspace を追加。
- Contents、ドキュメントタブ式ワークスペース、マップキャンバスプレビュー、Layer Properties、28 px GIS ステータスバーを追加。
- Figma の色、間隔、角丸、主要寸法をコード上のデザイントークンとして定義。
- Pane/Ribbon の状態保存と基本的なアクセシビリティ名・ツールチップを追加。
- QGIS プラグイン入口から Modern Shell を開き、公開 `QgisInterface` QAction を介して既存 GIS コマンドへ接続。
- QGIS 4.2 公開 API 統合ビルドと GUI smoke test を追加。
- QGIS 本体は ShellPreview パッケージに含めません。
