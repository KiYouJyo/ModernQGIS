# ModernQGIS v0.4.0 — Functional Preview

> 実際の QGIS ワークスペースと署名済み Windows インストーラーを備えた最初の機能プレビューです。QGIS 本体は同梱しません。

- 中央のプレースホルダーを実際の `QgsMapCanvas` に置き換え、現在の `QgsProject` から描画します。
- Contents を実際の `QgsLayerTreeView` に置き換え、表示切替、並べ替え、名前変更、アクティブレイヤー同期に対応しました。
- パン、ズームイン/アウト、全体表示、単一地物選択、選択へズーム、選択解除を接続しました。
- Add Data、レイヤープロパティ、属性テーブル、編集切替、Project New/Open/Save を QGIS 公開 API 境界へ接続しました。
- ModernQGIS 独自の距離・面積計測 MapTool を追加し、QGIS プロジェクト CRS、楕円体、`QgsDistanceArea` を利用します。
- レイヤーカードに実際のレイヤー名、ジオメトリ型/地物数、またはラスターバンド数を表示します。
- ステータスバーに座標、縮尺、回転、出力 CRS、レンダリング状態をリアルタイム表示します。
- ModernQGIS Launcher を追加し、ローカルの QGIS 4.x を検出して `QGIS_PLUGINPATH` 経由でプラグインを読み込めるようにしました。
- Windows x64 パッケージにはランチャーと QGIS プラグイン DLL を含め、バイナリとインストーラーを Authenticode 署名し SHA-256 を検証します。
- `qgisBundled=false` を維持し、QGIS 本体のコピーや長期フォークは行いません。
