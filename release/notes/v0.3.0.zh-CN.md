# ModernQGIS v0.3.0 — Shell Preview

> 开发预览；当前不发布 GitHub Release。

- 首次按照 Figma `QGIS Modern` 设计稿落地可复用 Modern Shell。
- 新增 40 px 自定义标题栏、Ctrl+K 全局搜索、Ribbon Tabs 与可折叠 Ribbon Workspace。
- 新增 Contents、文档标签式工作区、地图画布预览、Layer Properties 与 28 px GIS 状态栏。
- 将 Figma 色彩、间距、圆角与关键尺寸建立为代码级设计 token。
- 增加 Pane/Ribbon 状态持久化及基础无障碍名称与工具提示。
- QGIS 插件入口改为打开 Modern Shell，并通过公开 `QgisInterface` QAction 绑定现有 GIS 命令。
- 增加 QGIS 4.2 公共 API 集成编译工作流与 GUI smoke test。
- QGIS 本体仍不包含在 ShellPreview 包中。
